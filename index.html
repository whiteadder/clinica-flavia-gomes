FAQ

Perguntas frequentes

Como saber se este pode ser o momento certo para procurar apoio psicológico?

Pode fazer sentido quando existe sofrimento, mal-estar persistente, sensação de bloqueio ou vontade de compreender melhor o que está a acontecer.

É preciso ter uma questão muito clara para entrar em contacto?

Não. É frequente chegar com dúvidas ainda pouco organizadas. O primeiro contacto serve precisamente para ajudar a clarificar o pedido.

A mensagem inicial substitui uma consulta?

Não. A mensagem serve apenas para um contacto inicial. O acompanhamento psicológico começa apenas em contexto de consulta.

Como são tratados os dados enviados?

Os dados partilhados no contacto inicial destinam-se apenas à resposta ao seu pedido e são tratados com confidencialidade.
